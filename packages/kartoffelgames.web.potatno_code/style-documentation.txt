-- General
    - Border-radius of 4px.
    - For fixed sizes use 16px for 1rem.
    - Hover and action transitions times are 0.15s.
    - Content starts at 0.8rem padding. That includes icons, highlights and text. List background is not included and follows the *List* specification

-- List.
    - Colored border of 0.25rem on left. Full height (most of the time).
        - After that, an icon with 0.8rem horizontal padding on each side.
    - Padding of 0.8rem to left edge as it is considered a highlight.
        - Is the item selectable, has a background without border, the total padding is devided between, padding 0.5rem & margin 0.3rem
    - Selectable items:
        - Have a border radius.
        - Margin/gap of 0.3rem between them.
        - Padding of 0.3rem 0.6rem 0.3rem 0.5rem;

-- Panels
    - Dividers are 2px height with a 0.8rem gap on each side.
    - Content has a 1rem top and bottom padding.

-- "Windows"
    - Padding between windows is 0.3rem.

-- Inputs
    -- Follows the same rule as lists on paddings and margins. Having a 0.3rem margin and 0.5rem padding.
    -- General height of 2rem.
    -- Inner padding of 0.3rem 0.5rem.
    -- Transparent border of 1px. Can be highlighted on focus.
    -- Combining multiple inputs into a input group:
        -- The group itself has no padding.
        -- The inputs are either transparent or have the same background.
        -- Inputs have the same height and border radius as parent.
        -- Inputs have a 0.8rem padding, except some buttons. Problem are select boxes with internal padding.
            -- Buttons are the same width as height when they are single icons.
        -- Inputs are seperated by a divider with a with of 2px.
            -- No horizontal padding or margin.
            -- Vertical padding of 0.3rem pixel from input group.

-- Actions
Scale to 0.98 or translate 1px, based on looks on clicks.
 - Buttons usually Scale
 - Action such as dropdowns usually translate.

-- Popups
 - Animation time is 0.15s
 - Transition from opacity 0 to 1.
 - Transition from Translate(0 -20|20) to Translate(0 0)
